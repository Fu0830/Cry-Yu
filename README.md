# Cry-Yu 结单小票机

基于原版 [receipt-shop](https://github.com/Fu0830/receipt-shop) 复制改造的**独立定制版**，与原版及其他版本互不影响。

## 定制内容

- 俱乐部二选一（随票面与盖章署名同步切换）：
  - **OKB Club**（OKB CLUB）→ 盖章署名 **小与**（XIAO YU）
  - **冷空气Club**（COLD AIR CLUB）→ 盖章署名 **cry**（CRY）
- 盖章署名固定显示，不可关闭。
- 独立本地存储键：`cry-yu-v1`，与其他版本存档互不串。

## 本地预览

直接用浏览器打开 `index.html` 即可。
